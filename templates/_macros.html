{# Reusable metric label with an inline ⓘ tooltip that deep-links to /glossary. Usage: {% from "_macros.html" import metric %} {{ metric('Annualised Vol', 'annualised_vol') }} The tooltip text and the glossary entry both come from the GLOSSARY Jinja global (registered in app.py), so there is a single source of truth. `label_cls` styles the label text; pass the classes the bare label used to have. #} {% macro metric(label, key, label_cls='') -%} {%- set g = GLOSSARY.get(key) -%} {{ label }} {%- if g %} {{ g.short }} Details → {%- endif %} {%- endmacro %}
